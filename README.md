# Sperta Web

Sperta Web adalah aplikasi web modern berbasis React dan terintegrasi dengan Firebase. Proyek ini menyediakan antarmuka responsif, fitur pemutar musik, galeri gambar, serta routing dinamis.

## Fitur

- Antarmuka responsif (Tailwind CSS)
- Routing tanpa reload (react-router-dom)
- Integrasi Firebase (Hosting, Firestore, Auth)
- Ikon lucide-react
- Pemutar musik & galeri gambar

## Teknologi

- React 18, TypeScript, Vite
- Tailwind CSS
- Firebase
- ESLint, PostCSS

## Instalasi

1. Clone repo:
   ```bash
   git clone https://github.com/Chell07/sperta-web.git
   cd sperta-web
   ```
2. Install dependensi:
   ```bash
   npm install
   ```
3. Salin `.env.example` menjadi `.env` dan isi sesuai kebutuhan.
   ```bash
   cp .env.example .env
   ```
4. Jalankan server:
   ```bash
   npm run dev
   ```

## Kontribusi
